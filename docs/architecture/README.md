## Representation rule

The repository contains two complementary architecture representations:

1. the consolidated architecture corpus at the repository root;
2. the finer-grained Part-level documents under `parts/`.

The Architecture Series is design documentation. It does not by itself establish implementation, verification, validation, or qualification claims.
