# Project Status

NROS status should be described using evidence-backed maturity levels rather than broad labels such as complete, production-ready, or real-time.

## Maturity vocabulary

`PROPOSED → SPECIFIED → SCAFFOLDED → SIMULATED → IMPLEMENTED → TESTED → BENCHMARKED → INTEGRATION-TESTED → HARDWARE-VALIDATED → PRODUCTION-READY`

## Status rules

- A proposal is not an implementation.
- A scaffold is not a working feature.
- A simulation is not hardware validation.
- A passing test proves only what that test actually exercises.
- A benchmark is a measurement under stated conditions, not a universal guarantee.
- Production readiness requires explicit acceptance criteria.

## Source of truth

Current status should be reconciled with repository source, tests, CI evidence, and validation records before publication.
