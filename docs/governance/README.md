# NROS Governance

Governance documentation describes how NROS decisions, status, releases, and project direction are represented.

## Governance areas

- [Roadmap](roadmap.md) — planned direction and sequencing.
- [Status](status.md) — current project state and maturity boundaries.
- [Decision Records](decision-records.md) — durable architectural and project decisions.
- [Release Process](release-process.md) — release preparation and evidence expectations.

## Governance principle

Roadmaps describe intent. Status describes evidence-backed state. Decision records explain why choices were made. Release records establish what was actually shipped and verified.
