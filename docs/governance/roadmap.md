# Roadmap

The NROS roadmap describes intended project direction. It is not evidence that a capability exists.

## Roadmap layers

1. Architecture and specification work
2. Core implementation
3. Automated verification
4. Integration validation
5. Hardware validation
6. Release readiness

## Reading roadmap status

A roadmap item should identify its current evidence state when possible. Planned work must remain distinguishable from completed work.

## Maintenance

Update this document when project priorities change. Historical decisions should be preserved in decision records rather than rewritten into the roadmap.
