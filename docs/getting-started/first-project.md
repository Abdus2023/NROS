# First Project

The first-project guide should demonstrate the smallest repository-supported workflow rather than inventing a separate tutorial API.

## Workflow

```text
understand workspace
      ↓
select an existing supported example or crate
      ↓
build
      ↓
run
      ↓
observe output
      ↓
run associated tests
```

## Principle

Prefer an existing repository example over pseudo-code when documenting behavior. If a capability is only specified or scaffolded, label the example accordingly.

## Evidence

A successful example run demonstrates the behavior exercised by that example only. It does not establish the status of unrelated NROS subsystems.
