# NROS Concepts

This section explains the conceptual model of NROS without requiring the reader to understand the implementation.

## Core concepts

- [Overview](overview.md) — the problem NROS is intended to solve and its conceptual boundaries.
- [Design Principles](design-principles.md) — principles that guide the architecture.
- [Nodes](nodes.md) — the conceptual execution unit.
- [Messages](messages.md) — typed data exchanged between components.
- [Topics](topics.md) — named communication channels.
- [Services](services.md) — request/response interactions.
- [Actions](actions.md) — longer-running goal-oriented interactions.
- [Lifecycle](lifecycle.md) — component state and lifecycle concepts.

## Evidence boundary

Conceptual documentation describes the intended model. It does not, by itself, establish that a concept is implemented or validated in the current repository. Implementation and verification status belongs in the verification documentation.
