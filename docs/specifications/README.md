# NROS Specifications

Specifications define explicit contracts and invariants for NROS components and protocols.

## Specification areas

- [Types](types.md) — data and type-system contracts.
- [Protocols](protocols.md) — communication and state-machine contracts.
- [IPC](ipc.md) — inter-process communication requirements.
- [Transport](transport.md) — transport abstraction and behavioral requirements.
- [Safety](safety.md) — safety-related invariants and boundaries.

## Normative status

A specification describes what an implementation must satisfy. A specification is not evidence that the requirement is implemented.

Implementation and verification status must be established independently through repository evidence and tests.
