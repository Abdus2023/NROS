# Crate Reference

This page is the entry point for the NROS workspace crate reference.

## What belongs here

For each repository crate, reference documentation should record:

- crate name and path;
- purpose;
- public modules;
- exported types and functions;
- feature flags;
- dependencies that form part of the integration contract;
- supported targets;
- tests providing evidence for the documented surface.

## Source of truth

The Cargo workspace and crate source are authoritative for the existence of an API. This document should not enumerate APIs from design documents alone.

## Status

The detailed crate inventory should be generated from the current workspace and then reviewed for semantic accuracy. Until that inventory is completed, this page intentionally avoids presenting an invented crate list as authoritative.
