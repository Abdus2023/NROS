# NROS Reference Documentation

This directory is the navigation boundary for interface and reference-oriented documentation.

## Reference boundary

Reference material should describe concrete repository interfaces, types, configuration surfaces, commands, protocols, and other externally consumable contracts.

For architecture, use [Architecture Documentation](../architecture/README.md).

For verification and evidence, use [Verification Documentation](../verification/README.md).

For repository-wide structure, use [Repository Representation](../REPOSITORY_REPRESENTATION.md).

## Claim discipline

Reference documentation describes the repository surface. It must not imply implementation guarantees that are not supported by source and verification evidence.
