# NROS Reference

Reference documentation describes concrete repository interfaces.

## Reference areas

- [Crates](crates.md) — workspace and crate responsibilities.
- [CLI](cli.md) — command-line interfaces and supported commands.
- [Configuration](configuration.md) — configuration surfaces and defaults.
- [Environment](environment.md) — environment variables and platform assumptions.
- [API](api.md) — public APIs and stable integration surfaces.

## Accuracy rule

Reference pages must describe interfaces that exist in the repository. Proposed interfaces belong in specifications and must be labeled as such.

When an interface changes, its reference documentation should change with the implementation and verification evidence.
