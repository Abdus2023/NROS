# CLI Reference

This page documents command-line interfaces that are actually present in the NROS repository.

## Reference requirements

Each command should document:

- executable or package providing it;
- command and subcommand syntax;
- required arguments;
- options and defaults;
- input/output behavior;
- exit-status semantics;
- examples verified against the repository.

## Accuracy rule

Do not document a CLI command merely because it appears in a specification, roadmap, or example design. The command must exist in the current source tree or be explicitly marked `PROPOSED`.
