# Safety Remediation

Safety remediation records corrective actions taken in response to identified risks, failures, or verification gaps.

## Remediation record

Each item should capture:

- finding;
- affected boundary;
- severity;
- corrective action;
- verification method;
- resulting evidence;
- remaining limitations.

## Historical material

Existing remediation and audit records should remain available as historical evidence. This page is the navigational and methodological entry point; it does not replace the original records.

## Status rule

A remediation item is not considered closed merely because code changed. Closure requires the evidence defined by the finding and its acceptance criteria.
