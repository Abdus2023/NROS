# NROS Operations

Operations documentation describes how NROS systems are deployed, observed, diagnosed, and troubleshot.

## Guides

- [Deployment](deployment.md) — deployment boundaries and release considerations.
- [Observability](observability.md) — logs, metrics, traces, and runtime visibility.
- [Diagnostics](diagnostics.md) — diagnostic information and evidence collection.
- [Troubleshooting](troubleshooting.md) — systematic failure investigation.

## Operational evidence

Operational documentation must distinguish a supported production operation from a prototype, simulation, demonstration, or development-only command. Availability of an interface does not establish operational readiness.
